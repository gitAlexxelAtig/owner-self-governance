# 软件规格说明书 (SRS)

**产品名称**: 业主自治宝 (Owner Self-Governance Treasure)  
**载体**: 微信小程序  
**定位**: 国内首款专为无业委会住宅小区打造的业主自救自治工具  
**Slogan**: 无业委会也能维权，1元自治守好家园  
**版本**: 1.0  
**日期**: 2026-03-08  
**作者**: 惊蛰

---

## 1. 引言

### 1.1 目的
本文档详细描述「业主自治宝」微信小程序的软件需求规格，为开发团队提供清晰的开发指导。

### 1.2 产品背景
- **现状痛点**:
  - 全国无业委会小区占比超过60%
  - 物业侵权时业主无组织、无对策
  - 业主意见分散，难以形成合力
  - 大多数业主不懂相关法律法规
  - 邻里之间联络困难，信息闭塞
  - 维权成本高、流程复杂

- **市场空白**: 国内尚无专门针对无业委会小区的自救自治工具

- **产品价值**: 1元/年/小区，让每个无业委会小区都能低成本实现业主自治

### 1.3 目标平台
- **微信小程序**（主要）- 即用即走，适配全年龄段
- **支付宝小程序**（次要）
- **适配**: iOS/Android 双端

## 2. 总体描述

### 2.1 产品概述
「业主自治宝」是专为无业委会住宅小区打造的业主自救自治工具。通过"1元/年"的极低门槛，帮助业主建立组织、凝聚共识、维护权益、推进自治。

### 2.2 核心功能架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                           业主自治宝                                 │
│                    「无业委会也能维权」                               │
├──────────────────┬──────────────────┬──────────────────┬─────────────┤
│    实名准入       │    法律武器库     │    集体表决       │   业主联络   │
├──────────────────┼──────────────────┼──────────────────┼─────────────┤
│ • 微信登录       │ • 民法典查询     │ • 发起表决       │ • 议事圈    │
│ • 实名认证       │ • 物业管理条例   │ • 一户一票       │ • 紧急通知  │
│ • 房屋核验       │ • 侵权场景匹配   │ • 实时公示       │ • 通讯录   │
│ • 1元缴费       │ • 维权话术模板   │ • 表决报告       │ • 进度跟踪  │
└──────────────────┴──────────────────┴──────────────────┴─────────────┘
```

### 2.3 收费规则（核心商业模式）

| 项目 | 规则 |
|------|------|
| **收费标准** | 1元 / 微信账号 / 单个小区 / 1个自然年 |
| **缴费方式** | 微信支付直达，自动记录有效期 |
| **到期提醒** | 轻量提醒续费 |
| **缴费权益** | 该小区内无限次使用全部功能 |
| **未缴费限制** | 仅可浏览基础法律内容，无法参与表决、发言、发起 |

### 2.4 目标用户

| 用户类型 | 特征 | 核心需求 |
|----------|------|----------|
| **维权发起人** | 遭遇物业侵权，想组织维权 | 法律依据、表决工具、联络业主 |
| **热心业主** | 关心小区事务，愿意参与 | 了解法规、参与决策、监督物业 |
| **普通业主** | 关注权益，但不愿出头 | 获取信息、简单参与、匿名表达 |
| **业委会筹备人** | 想推动成立业委会 | 组织工具、流程指导、业主动员 |

## 3. 功能需求

### 3.1 实名准入系统（基础安全）

#### 3.1.1 微信快捷登录
- **登录方式**: 微信一键登录
- **多小区绑定**: 一个账号可绑定多个小区
- **小区独立缴费**: 每个小区单独缴纳1元年费

#### 3.1.2 实名认证
- **必填信息**:
  - 真实姓名
  - 手机号（短信验证）
  - 楼栋房号（精确到门牌号）
- **认证状态**:
  - 待认证：已提交，等待审核
  - 已认证：通过核验
  - 已拒绝：信息不符

#### 3.1.3 房屋信息核验
- **核验方式**（三选一）:
  1. **房产证拍照**: 上传房产证照片（自动打码处理）
  2. **物业证明**: 物业公司开具的业主证明
  3. **邻居担保**: 2户以上已认证业主确认
- **人工审核**: 后台24小时内完成审核
- **隐私保护**: 房号脱敏显示（如：1栋**室）

#### 3.1.4 缴费系统
- **缴费入口**: 认证通过后提示缴费
- **缴费金额**: 固定1元
- **支付方式**: 微信支付
- **有效期**: 1个自然年（如2026.03.08-2027.03.08）
- **续费提醒**: 到期前7天、1天分别提醒
- **缴费记录**: 可查看历史缴费记录

---

### 3.2 权威物业法律库（自救核心依据）

#### 3.2.1 官方法条库
- **国家层面**:
  - 《民法典》物权编（业主权利）
  - 《民法典》合同编（物业服务）
  - 《物业管理条例》
- **地方层面**: 各省市物业管理实施细则
- **更新机制**: 实时同步最新法规

#### 3.2.2 侵权场景智能匹配
**覆盖场景**:
| 侵权类型 | 典型表现 | 对应法条 |
|----------|----------|----------|
| 乱收费 | 擅自提高物业费、乱收费项目 | 民法典939条 |
| 侵占公共收益 | 广告费、停车费不公示 | 民法典282条 |
| 服务不达标 | 卫生差、安保缺失、设施不维护 | 物业服务合同 |
| 擅自入驻/解聘 | 未经业主同意更换物业 | 民法典278条 |
| 违规改造 | 擅自改变公共设施用途 | 民法典271条 |
| 账目不透明 | 公共收益不公示、不审计 | 民法典943条 |

**功能**: 业主选择侵权场景 → 自动匹配相关法条 → 展示维权依据

#### 3.2.3 标准化维权工具
- **维权话术模板**: 针对不同场景的标准沟通话术
- **投诉函模板**: 
  - 给物业的整改通知书
  - 给街道/住建局的投诉信
  - 律师函模板
- **投诉渠道**: 一键复制联系方式
  - 住建局物业科
  - 街道办物业办
  - 12345市民热线
  - 市长信箱

---

### 3.3 业主集体表决系统（无业委会也能做决定）

#### 3.3.1 发起表决
- **发起资格**: 已缴费业主
- **表决类型**:
  - 维权投诉（如：要求物业整改）
  - 物业整改要求（如：修复设施）
  - 选聘新物业意向调查
  - 其他公共事项
- **表决内容**:
  - 标题
  - 详细说明
  - 选项（支持/反对/弃权）
  - 截止时间

#### 3.3.2 投票规则
- **投票资格**: 已认证且已缴费的业主
- **投票原则**: 一户一票（按房屋产权）
- **防刷票机制**:
  - 实名认证绑定
  - 一房一号
  - 微信账号唯一性
  - 投票行为分析

#### 3.3.3 实时公示
- **实时数据**: 当前投票数、参与率
- **结果趋势**: 支持/反对比例
- **匿名保护**: 仅显示投票结果，不显示个人投票

#### 3.3.4 表决报告
- **自动生成**: 表决结束后自动生成
- **报告内容**:
  - 表决事项
  - 参与业主数
  - 投票结果（支持/反对/弃权）
  - 参与率
  - 表决时间
- **下载功能**: PDF格式下载
- **法律效力**: 可作为维权佐证（不替代法定业委会程序）

#### 3.3.5 历史表决
- **存档查询**: 所有表决永久存档
- **分类筛选**: 按类型、时间筛选
- **结果追溯**: 查看历史表决结果

---

### 3.4 小区内部联络系统

#### 3.4.1 本小区专属议事圈
- **准入限制**: 仅限本小区认证且缴费业主
- **功能**:
  - 发帖讨论
  - 评论回复
  - 点赞
  - @其他业主
- **话题分类**:
  - 维权讨论
  - 物业监督
  - 公共事务
  - 邻里互助
- **合规审核**: 后台自动+人工审核，严禁违法言论

#### 3.4.2 紧急通知
- **发送权限**: 发起人或管理员
- **通知范围**: 一键@全体缴费业主
- **通知方式**:
  - 小程序内消息
  - 微信服务通知（可选）
- **使用场景**: 紧急维权行动、重要表决提醒

#### 3.4.3 自愿式业主通讯录
- **隐私设置**: 业主自主选择是否公开联系方式
- **显示内容**: 昵称、楼栋（可选手机号）
- **搜索功能**: 按楼栋、昵称搜索
- **快捷联系**: 一键拨打电话、加微信
- **使用场景**: 线下集结、分工维权

---

### 3.5 维权进度跟踪系统

#### 3.5.1 维权档案
- **档案创建**: 发起维权时自动生成
- **档案内容**:
  - 维权事项
  - 涉及业主
  - 投诉时间
  - 对接部门
  - 进展状态

#### 3.5.2 进展状态
- **状态流转**:
  ```
  已发起 → 已受理 → 处理中 → 已回复 → 已解决
             ↓
          被驳回（可重新发起）
  ```
- **状态更新**: 发起人更新，其他业主可见

#### 3.5.3 证据云端存储
- **证据类型**:
  - 图片（合同、收费单、违规照片）
  - 视频（物业违规行为录像）
  - 文档（往来函件、投诉记录）
- **存储方式**: 云端加密存储
- **安全保护**: 仅维权相关人员可见
- **下载导出**: 打包下载用于诉讼

#### 3.5.4 时间轴记录
- **自动记录**: 维权关键节点自动记录
- **时间线展示**: 可视化时间轴
- **提醒功能**: 关键节点到期提醒

## 4. 非功能需求

### 4.1 性能需求
- **加载时间**: 首屏<2秒，其他页面<1秒
- **并发支持**: 支持单小区5000人在线表决
- **稳定性**: 99.9%可用性
- **响应速度**: API响应<500ms

### 4.2 安全需求
- **数据加密**: 传输加密（HTTPS）、存储加密
- **隐私保护**: 业主信息严格保密，不脱敏不展示
- **实名认证**: 防止非业主混入
- **数据隔离**: 各小区数据完全隔离
- **操作日志**: 所有操作留痕，可追溯
- **防攻击**: DDoS防护、SQL注入防护

### 4.3 合规需求
- **内容审核**: 自动+人工审核，严禁违法言论、造谣
- **隐私合规**: 符合《个人信息保护法》
- **数据留存**: 按法规要求留存必要数据
- **免责声明**: 明确产品定位（辅助工具，不替代法定程序）

### 4.4 兼容性
- **微信版本**: 基础库2.20+
- **手机系统**: iOS 11+, Android 6+
- **屏幕适配**: 支持各种尺寸手机

## 7. 技术架构

### 7.1 技术栈
- **前端**: 微信小程序原生开发 / Taro
- **后端**: Node.js + Express / Java Spring Boot
- **数据库**: MySQL（业务数据）+ Redis（缓存）
- **文件存储**: 阿里云OSS（证据存储）
- **支付**: 微信支付API
- **消息推送**: 微信订阅消息

### 7.2 核心数据模型

```
用户表 (User)
├── user_id (微信openid)

├── room_number
```
